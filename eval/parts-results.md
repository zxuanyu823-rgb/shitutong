# 形体分析建模：测试记录

## 为什么要改
实拍测试“带凸台的轴承座”（底板圆角 + 底面通槽、与圆筒相切的支撑板、肋板、带孔凸台与圆筒相贯）时，识图基本正确，但重建只到 59%：
原来的做法是让大模型一次写出整个形体的建模步骤，各部分的相对位置、切点坐标都要它自己算，错一处整体就偏；
程序自己的候选（外轮廓拉伸求交 + 挖孔 + 挖切搜索）对凸台、相切板这类结构无能为力，理想读数下也只有 75%。

## 新的分工
- 大模型：按“形体分析法”列出组成部分（叠加：底板、支撑板、肋板、圆筒、凸台…；挖切：孔、槽、缺口…），
  每个部分给出反映实形的视图、轮廓顶点、沿投射方向的范围；圆柱和孔给圆心、半径。
- 程序（web/js/recon/parts.js）：
  1. 坐标吸附到量好的图线坐标上（容差为总体尺寸的 1.5%），圆吸附到识别出的圆和圆弧上；
  2. 圆角板、与圆柱相切的支撑板用“顶点 + 圆的凸包”建模，切点由程序算；
  3. 微调：每个部分的范围在相邻坐标里试，按另两个视图里的孔轮廓确定孔深，补上程序识别到的圆孔，去掉多余部分，
     只保留让三视图更吻合的改动（时间上限 25 秒）；
  4. 仍有差异时，把差异（同样的坐标约定）和反算图交给大模型改部件清单，再由程序建模微调。
- 与原来的“看图直接建模”同时进行，按图线吻合度取优，简单题不受影响。

## 程序补齐（1.8.5）
实拍时最后胜出的常是“看图直接建模”的候选，不经过形体分析的微调，肋板压在圆筒下面的那段一直补不上。现在所有大模型候选建模后都过一遍补齐。
模拟“直接建模的方案里肋板只到圆筒前面”，与正确答案的吻合度（真值）：

| 量线条件 | 补齐前 | 补齐后 |
|---|---|---|
| 理想 / 合成照片 1 / 2 / 3 | 97.8% / 97.7% / 97.7% / 97.7% | 99.1% / 99.1% / 99.1% / 99.1% |
| 同上，且俯视图圆筒下面的虚线没量到 | 97.8% / 97.7% / 97.7% / 97.7% | 99.1% / 99.1% / 99.1% / 99.1% |

**没见过的形体上检验**（防止只对这一道题调好）：用生成器换一个从没用过的种子，生成 40 个随机的支架、轴承座类形体，
把每个叠加部件分别从一头截短 40%（模拟大模型漏画一截），共 178 例：补齐后 161 例改善、104 例基本复原（>99%）、0 例变差，
平均吻合度（真值）86.1% → 95.6%；40 个没截短的原样形体，补齐没有让任何一个变差。

两个坑：另加一块长方体贴上去，贴合面布尔运算后可能留下双层面，视图里还是那条线——所以改成把肋板截面本身拉长，并去掉共线的点；碰到支撑板时多伸进去 0.02，不留夹缝。

## 顺带修复
- 支撑板与圆筒相切时，切点比圆柱网格多凸出一丝，布尔运算留下窄面，三视图在切点处多画一条线（违反“相切处不画线”）。
  现在柱体截面上落在圆周上的顶点会挪到网格边上；凸包里与已有圆柱重合的圆略微缩小，埋进圆柱里，不产生重合面。
- 编辑校验器支持带 `circles` 的柱体，“助教·对话改模型”能打开形体分析建出的模型。

## 回归
标准条件 59/60、带标注 35/36（与改动前相同）；前三道梯度题结果不变；界面回归无报错。
